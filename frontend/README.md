# Werewolf Game Frontend

狼人殺遊戲前端應用

## 安裝

```bash
cd frontend
npm install
```

## 開發

```bash
npm run dev
```

訪問 http://localhost:5173

## 構建

```bash
npm run build
```

## 專案結構

- `src/pages/` - 頁面組件
- `src/components/` - UI 組件
- `src/services/` - API 和業務邏輯
- `src/hooks/` - 自訂 React Hooks
- `src/context/` - 全域狀態管理
- `src/styles/` - 樣式文件
